## Запуск

Из корня клонированного репозитория при работающем Docker и установленном Docker Compose выполните:

```sh
docker compose -p roomly run --build --rm tests
```

Нужен доступ к опубликованной форме, а при первой сборке также к реестру образов и пакетам Python. После запуска JUnit-отчёт находится в `artifacts/junit.xml`, материалы неожиданных падений — в `artifacts/browser/`. Для BUG-01 ожидается `XFAIL`: на 29 минут форма выдаёт подтверждение. Когда форма начнёт отклонять такую заявку и показывать ошибку длительности, pytest сообщит `XPASS(strict)`. После проверки исправления можно снять метку `xfail`.

## Затраченное время и участие ИИ

Подготовка чек-листа, ручная проверка и автоматизация до первого полного прогона заняли около часа с учётом обсуждения и настройки Docker. Демонстрация в Chrome и оформление репозитория проходили позже.

Я самостоятельно проверил форму в браузере. В частности, попробовал ввести почту на кириллице и вынес вопрос о допустимом формате адреса в отчёт. Вместе с Codex обсудил техники тест-дизайна и проверку со сменой комнаты. Для автоматизации выбрал три сценария: четыре и пять участников в Малой и бронь на 29 минут.

Codex помог с чек-листом и отчётом, сохранил снимки и журналы для найденных расхождений, написал и запустил автотесты. Логику тестов и результат воспроизведения BUG-01 разобрали совместно.
